# Calculadora-de-IMC
Este programa foi feito em PHP. Ele calcula o Índice de massa corporal do usuário (IMC) com base no peso e na altura dele. Para executar este programa, baixe o arquivo ZIP e descompacte-o. Após isso, certifique que o Xampp está instalado em seu computador. Caso esteja, entre no Xampp e clique em start. Feito isso, entre no seu navegador e digite o seguinte: http://localhost/Calculadora-de-IMC-main/Index.php
Feito isso, prontinho, é só digitar seu peso e sua altura e clicar em calcular. Você verá o seu IMC instantaneamente.
